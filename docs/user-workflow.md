# User workflow

The order a renter goes through in Vacate, from sign-up to getting the deposit back. Steps marked **agent** happen without the user; everything that leaves the system (emails, calls, posts, accepted deals) waits for the user's approval first.

## 1. Sign in and set the deadline

1. Sign in with Google.
2. Answer the first question: **what's your last day in the apartment?** Everything else is scheduled backward from this date.
3. Add the address, deposit amount, and the landlord's name and email.
4. Upload the lease (PDF).
5. **Agent:** reads the lease and pulls out the rules: notice period, cleaning requirements, key fees, anything about carpets or walls.

## 2. Contact the landlord

6. **Agent:** drafts the notice to vacate and the pre-move-out inspection request. User approves, agent sends.
7. **Agent:** reads the landlord's reply and any move-out documents they attach.
8. **Agent:** builds the checklist: every task dated, tagged with the lease clause or law it comes from, and the amount the landlord could deduct if it's skipped.

## 3. Document the apartment

9. User takes photos of every room (move-out condition).
10. **Agent:** keeps them with timestamps as evidence for the deposit.

## 4. Choose how to clean

11. **Agent:** looks up cleaning-service prices online and shows the options next to the do-it-yourself checklist.
12. User picks: book a service (agent books it before the inspection) or clean it themselves (agent gives the room-by-room list).

## 5. Sell or donate what you're not keeping

13. User uploads photos of each item.
14. User sets the **sell-by deadline** (defaults to a few days before move-out).
15. For each item, user enters the **asking price** and the **minimum price**.
16. **Agent:** describes each item from the photo (what it is, model number, condition) and writes the listing.
17. User approves the listing; it goes on the item's page and is posted to Craigslist, Buy Nothing and Marketplace.
18. **Agent:** answers buyers by text, negotiates, and never goes below the minimum.
19. **Agent:** as the deadline gets close, lowers the asking price step by step (never below the minimum).
20. **Agent:** when several buyers are interested, ranks them by price **and** by whether they can pick up before the deadline, then recommends one.
21. User approves the deal; agent confirms pickup time and a public meeting spot.
22. Anything left near the deadline becomes a free Buy Nothing post.

## 6. Move

23. **Agent:** sizes the truck from the items being kept, gets mover quotes, and helps reserve a U-Haul.
24. **Agent:** reminds the user to apply for SFMTA no-parking signs (5+ business days ahead).

## 7. Hand back the keys

25. Final walkthrough: user takes timestamped photos of every room and returns keys and fobs.
26. **Agent:** sends the landlord the forwarding address.
27. **Agent:** tracks the 21-day deposit deadline and, if it's missed, drafts a follow-up citing the law.

## Later, not in the first version

- The agent suggesting asking and minimum prices from comparable second-hand listings.
- Voice calls to the landlord and buyers (Bland).
- Move-in planning.
